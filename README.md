<h1 align="center">Tune Music</h1>

<p align="center">Клиент Яндекс Музыки для Windows с темами, плагинами и улучшениями — одно приложение, без отдельного официального клиента.</p>

## Возможности

- **Музыка из коробки.** При первом запуске Tune скачивает проверенную версию интерфейса Яндекс Музыки с сервера Яндекса и проверяет её подпись (SHA-512). Официальный клиент ставить не нужно.
- **Темы и скрипты.** Подходят аддоны PulseSync и Next Music: их можно поставить из каталога, из файла (.zip, .pext, .tar.gz, .css, .js), по ссылке на GitHub или перенести из установленных модов одной кнопкой. Настройки аддонов, их картинки и шрифты работают как в родных модах.
- **Каталог** открытых аддонов из [Next Music Extensions](https://github.com/Web-Next-Music/Next-Music-Extensions) и репозиториев авторов, с описаниями и обновлениями.
- **Синхронный текст песен** для треков, у которых его нет в Яндексе (LRCLIB): строки подсвечиваются по ходу песни, клик перематывает.
- **Discord** без регистрации своего приложения: название активности, ссылки при клике, кнопки, обложка, время трека.
- **Windows:** медиапанель и медиаклавиши, трек в заголовке окна, сворачивание в трей, автозапуск.
- **Скорость воспроизведения**, громкость колесом мыши, горячие клавиши, масштаб интерфейса.
- **Весь трафик из одного процесса** — удобно для VPN с правилами по программам.

Управление — в окне Tune: кнопка «Tune» в сайдбаре музыки или меню значка в трее.

## Установка

Скачайте установщик или переносную версию из [выпусков](https://github.com/tune-music/tune/releases/latest). Нужен Windows 10 или 11 (WebView2 уже есть в системе).

## Сборка

Нужны Rust (MSVC), Visual Studio Build Tools с компонентом C++ и `cargo install tauri-cli`.

```bash
cd src-tauri
cargo tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis`.

## Как это устроено

- `src-tauri/src/client.rs` — загрузка и проверка интерфейса Яндекс Музыки (версия закреплена и обновляется вместе с релизами Tune).
- `src-tauri/src/intercept.rs` — интерфейс отдаётся локально по адресу music.yandex.ru внутри WebView2; там же адрес `127.0.0.1:2007` для файлов аддонов.
- `src-tauri/src/addons.rs`, `repo.rs` — аддоны в формате PulseSync и Next Music, каталог.
- `src-tauri/inject/` — код страницы: мост оболочки, совместимые `pulsesyncApi` и `nextmusicApi`, встроенные улучшения.
- `ui/` — окно Tune.

Отладка: `tune-music.exe --tune-debug` открывает DevTools-порт 9333 на localhost.

## Данные

`%APPDATA%\dev.tune.music`: `addons/` — установленные аддоны (по папке на каждый), `settings.json` — настройки, `client/` — интерфейс Яндекс Музыки.
